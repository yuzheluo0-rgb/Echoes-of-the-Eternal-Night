# 先前的战斗原型

战斗代码保留在 `src/App.tsx`、`src/engine.ts`、`src/effects.tsx` 和 `src/styles.css`。当前默认入口是 `src/opening/Opening.tsx`，载入与序章流程不会进入战斗。

先前实现的范围为第一章 N1「标准尸群」三波遭遇，包含六张手牌、三拍排序、数字与印记组合、共鸣与终奏、三路与守卫、燃烧、死亡反应、换牌与保留、敲钟、回响与狂奏、胜败与重试。

战斗有独立规则测试：`npm test`。覆盖开发文档第 19 节数值示例、40 个固定种子的资源不变量和相关边界条件。原型不包含完整三章流程或平衡验证。
