# 主世界日夜与阅读界面

2026-09-15。入口：`http://127.0.0.1:5173/#/world`，或双击项目根目录 `start.bat`。

## 时间

从第一天 07:00 开始，默认现实 1 秒对应游戏 1 分钟，因此一天为现实 24 分钟。时间只在活跃探索时推进，不依赖帧率。顶部中央时钟显示日数、时段和 HH:MM；窄屏将时钟放在地图标题下方。黑金时钟有绕行荧光边、细光环与流动金色数字，减少动画与阅读弹窗时停止装饰动效。

- 1×：一天 24 分钟；3×：8 分钟；6×：4 分钟。
- “驻足此刻”只暂停世界时间，云、水和鸟仍可活动。
- 可等到下一次清晨 07:00、中午 12:00、下午 15:00、傍晚 18:00、夜晚 22:00；只向前等待，必要时进入下一天。
- 地点、支线、奇遇、手记、说明等原生弹窗暂停探索、时间和重复绘制。时间面板自身不暂停探索，以便观察调整后的光照。
- 隐藏页面与离开地图不补算离线时间。日数、时刻、流速和暂停状态保存于 `eternal-night-world-clock-v1`，与探索存档分开。

“减少环境动画”与时间暂停各自独立：前者冻结天气与待机动画，后者冻结日夜。二者一起开启后，静止画面无需连续重绘。

## 光影

以一天中的 12 个光照关键点平滑插值，不使用整页滤色。暗金版采用烟灰天空、深墨色海水与低饱和地貌，白天仍有明朗受光面，夜晚突出冷月与暖灯。实际方向光控制建筑与树木的明暗面和地面阴影：早晨暖光与长影，中午高太阳与短影，下午西斜金光，傍晚玫瑰色天空，夜间冷月光。天空半球光、地面反照色、雾、海水与溪流颜色同步过渡。水面高光随日月方向移动，亮斑有断续变化。

入夜后的光源包括营火、建筑窗户、入口灯、随身提灯、灯塔灯室、熔炉与火山口、晶石和血海符文。116 个固定发光位置使用合批光晕与贴合地面的衰减光斑；离镜头最近的四处光源使用可复用的局部点光，照亮周围几何。人物另有随行提灯点光。雾海灯塔有缓慢扫过的光束，晶石有独立自发光材质，雪与普通石材保持自然受光。

性能策略：太阳／月光共用一个有阴影的方向光；通常间隔至少 2.4 秒且方向确有变化时刷新环境阴影。近处点光无独立阴影贴图；远处灯光合批为两个绘制对象。保留自动像素预算、共享几何与按需绘制。人物使用随行接触阴影。

## 阅读界面

特殊地点、关卡、支线、奇遇、旅途手记、图志、信标及地图说明使用统一的阅读尺寸：

| 内容 | 尺寸 |
| --- | --- |
| 主要正文、操作按钮 | 16px |
| 说明、目标状态、奖励细节 | 14px |
| 关卡与地点名称 | 17～18px |
| 弹窗标题 | 28～32px |
| 弹窗宽度 | 最多 760px，随小屏缩窄 |
| 按钮高度 | 44～48px 起 |

长段落改用无衬线字体，正文行高 1.9。弹窗标题与关闭按钮固定，内容区域独立滚动；小屏将关卡操作、信标和图志改为单列，保留正文字号。时间面板也采用 16px 说明与较大的时间数字。

## 验证

- 29 项自动测试全部通过，新增 5 项覆盖真实日长、帧率无关推进、时段与午夜边界、暂停、等待、非法存档与订阅频率。
- 实际浏览器验证 3× 推进、时间暂停、等待与光照过渡、弹窗暂停、保存／读档、离开不补时、键盘关闭、减少动画时按需绘制。
- 检查 1440×960、1280×720、960×640、1920×1080、390×844、768×1024、844×390、320×568 八种视口；正文至少 16px、辅助说明至少 14px，没有弹窗横向溢出，关闭按钮滚动时保持位置。
- 调整后重新通过支线接取、秘境发现、奇遇选择、旅途手记、免费与付费传送、跨区行走、读档和手机图志完整流程。
