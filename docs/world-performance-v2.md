# 主世界性能优化记录

2026-09-14，针对实机卡顿调整。地图、美术素材和地点内容沿用第二版。

## 实现

- 将同材质的地形、水面合并绘制，拾取继续使用独立的地块几何，保留选格准确性。
- 总览使用较轻的地形、岩石、草丛与建筑几何。放大到每世界单位约 50 屏幕像素时恢复原精细模型，缩小时使用独立阈值，避免反复跳换。
- 限制三维画面最多绘制 60 帧/秒，为输入和浏览器合成保留余量。位置、行走与风动按经过的时间更新。
- 阴影复用缓存，环境阴影约每 250 毫秒更新，行走时约每 50 毫秒更新。辉光改为四分之一尺寸的亮部提取与两次模糊。
- 自动和流畅画质使用 FXAA，精细画质使用 2 倍 MSAA 和接触遮蔽。对不同抗锯齿方式同步切换针叶透明覆盖，避免叶缘发白。
- 镜头刻度、罗盘与标签按变化更新，避免旋转时反复渲染整个 React 界面。图志、镜头控制与底栏使用深色半透明面板，减少实时背景模糊开销。
- 悬停拾取最多约 30 次/秒；点击拾取即时响应。打开对话框后停止重复 GPU 绘制，后台页面停止渲染。
- 缓存地形的 CPU 几何数据，重新进入地图时复用计算结果；场景使用独立副本，卸载时释放对应 GPU 资源。

## 画质选择

右上角问号 → 画面质量。偏好通过 `eternal-night-world-quality` 独立保存。

| 选项 | 三维渲染像素预算 | 用途 |
| --- | --- | --- |
| 自动，默认 | 90 万，持续负载高时逐级降低至 65 万 | 自动平衡流畅度与清晰度 |
| 流畅 | 65 万 | 优先降低显卡负载 |
| 精细 | 240 万，像素比上限 1.5 | 更高清晰度、完整模型与接触光影，负载相应增加 |

文字和按钮保持屏幕原生分辨率。自动调整包含启动缓冲与冷却时间，并等镜头停止移动后再应用缓冲区尺寸变更。近景保留原细致几何与原纹理；自动、流畅模式的三维图像分辨率低于精细模式。

## 本机测量

Chrome 无头模式，Intel UHD Graphics / ANGLE D3D11，1440 × 960 视口、设备像素比 1。优化后每个场景采集至少 160 次实际绘制，排除前 20 次。统计口径为实际画面绘制间隔，浏览器回调频率单独记录。

| 场景 | 优化前典型帧间隔 | 优化后绘制间隔中位数 | 优化后 P95 |
| --- | --- | --- | --- |
| 总览 | 41.6 ms | 16.7 ms | 17.1 ms |
| 持续旋转 | 41.6 ms | 16.7 ms | 17.9 ms |
| 移动鼠标悬停 | 53.9 ms | 16.7 ms | 20.9 ms |

典型总览绘制调用从约 496 次降至约 111 次；阴影更新帧会增加。此轮自动画质的实际三维缓冲区为 1161 × 774。结果是本机短时测量，其他设备、精细画质及后台 GPU 负载会影响帧率。

原始记录：`.work/world-perf-before.json`、`.work/world-perf-release.json`；可通过 `node .work/world-perf-bench.cjs release` 复测。检查画质切换、近景恢复、暂停绘制、存档、选关与大窗口像素上限的脚本为 `.work/world-performance-check.cjs`。

规则与预算控制测试运行 `npm test`；生产构建运行 `npm run build`。
