# 主世界性能记录 · 卡通群岛版

2026-09-15。本版为 776 个六边格、48 处地点、跨格建筑、地貌桥梁与环境动态。

## 实现

地形合并绘制，树木和装饰使用共享几何与实例，建筑、桥梁按材质合批。桥面采用轻量几何。前版的整屏接触遮蔽、后期辉光和写实纹理不在当前渲染链路中，改用原生抗锯齿与 Lambert 光照。

环境阴影缓存，人物使用独立的随行软接触阴影。10 团云和 15 只鸟以实例更新；海水、溪流、熔岩、树叶和余烬在着色器中动画化。画面最多绘制 60 帧/秒，悬停拾取约 30 次/秒，标签最多约 20 次/秒并随缩放调整密度。

对话框、后台页面、减少动态模式停止不必要的绘制。声音短时预调度，关闭时停止定时器、淡出并回收音源。

| 画质模式 | 三维像素预算 |
| --- | --- |
| 自动 | 140 万，持续负载高时逐级降至 65 万，余量持续恢复后再升高 |
| 流畅 | 65 万 |
| 精细 | 240 万 |

像素比上限 1.5，界面文字保持原生分辨率。设置在右上问号中，选择会保存。

## 本机测量

Chrome 无头模式、Windows、Intel UHD Graphics / ANGLE D3D11，1440 × 960、DPR 1、自动画质、动态开启。每个情景采集 200 次实际绘制，排除前 20 次。行走通过真实界面的“前往此处”启动，包含状态更新、存档与跟随。

| 场景 | 绘制间隔中位数 | P95 | 本次峰值 |
| --- | --- | --- | --- |
| 全图总览 | 16.7 ms | 17.1 ms | 21.3 ms |
| 连续平移 | 16.7 ms | 20.6 ms | 48.2 ms |
| 连续缩放 | 16.7 ms | 21.0 ms | 29.9 ms |
| 实际行走与跟随 | 16.7 ms | 21.1 ms | 113.9 ms |
| 火山动态近景 | 16.7 ms | 17.1 ms | 107.6 ms |

典型绘制约 60 FPS，仍有少量长帧。手机做了布局与交互模拟，没有将其当作手机实机帧率。全图约 135 次主绘制调用、218,837 个三角形、220 个粒子点，渲染缓冲区 1440 × 960。静态合批降低调用数，但近景仍会绘制部分大合批几何。
