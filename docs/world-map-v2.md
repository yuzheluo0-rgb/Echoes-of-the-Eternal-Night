## 交付范围

本次是可实际操作的主世界与关卡选择原型，包含 127 个六角格、8 个连续地貌区域、8 个特殊地点，每个地点有 3 个可选关卡。关卡选择记入旅程，不会启动尚未制作的地图关卡战斗。地图、地点故事和关卡名称是基于永夜守夜人世界观创作的初版内容，可继续迭代。

采用真实 Three.js 三维场景及正交相机形成 2.5D 视角。自由水平旋转 360°，俯仰角保留在棋盘上方；滚轮和双指缩放，右键或双指平移。侧面按钮支持旋转、缩放、定位人物和恢复总览。

- 草原：起伏草甸、弯曲草叶与风动、稀疏松树、篝火与营帐。
- 森林：透明针叶枝条组成的多层三维树冠、树干与分枝、苔藓地表、古老圣所。
- 沙漠：带风纹的起伏沙丘、金字塔与残柱。
- 悬崖：连续高地、侵蚀轮廓、分层岩石与哨塔。
- 雪山：细分的连续山脊、根据高度与坡度分布的积雪、可行走的隘口与霜冠神殿。
- 大海：动态波面、随水深变化的岸线与细浪、礁岛、帆船与港口栈桥。
- 血海：暗红动态海面、黑曜石尖峰与献祭台。
- 雾海：漂移的透明雾层、浮岛、木桥与灯塔。

山体、树木、岩层、建筑、船只、桥梁和守夜人小人均在项目中自建模。人物包含兜帽、眼部微光、胸甲、披风、短剑、提灯、手臂与腿部，沿真实相邻六角格插值行走并转向，行走与路线高度随连续地形变化。光照包含暖色主光、冷色轮廓光、半球环境光、提灯点光、预过滤环境反射、实时阴影、地形接触遮蔽、克制的辉光与色调映射。

## 探索操作

1. 单击地块预览路线，再次点击同一地块或点击「前往此处」开始行走。
2. 左侧世界图志或地图标签可定位特殊地点；手机使用左上角图志按钮。
3. 到达特殊地点后自动出现关卡选择。点击一张关卡并确认，会记住旅程目标，可以继续探索。
4. `W / E / D / S / Q / A` 对应六个相邻方向；空格定位人物。对话框和表单操作不会触发键盘移动。
5. 右上角扬声器启用本地合成的环境声、交互声、到达钟声和随地表变化的脚步声。
6. 右上角问号中的「画面质量」默认为自动，可选流畅或精细；选择会保存。操作说明中的减少动态与画质选项独立。

位置、探索地点和已选关卡通过独立键 `eternal-night-world-v1` 保存在 localStorage。旧载入界面和旧战斗存档互不覆盖。存档会验证坐标、通行状态、地点及关卡名称；无法使用存储时仍可在本次页面中游玩。

## 实现与边界

- `src/world/worldData.ts`：地图布局、地点定义、六角距离、A* 寻路、存档验证。
- `src/world/WorldScene.ts`：三维场景、自建模型、材质、灯光、移动动画、拾取与镜头控制。
- `src/world/landscapeGeometry.ts`：共享高度场、细分地块、坡面法线、侵蚀岩石、分层岩壁、针叶树冠与草丛。
- `src/world/landscapeMaterials.ts`：岩石三向采样、坡面积雪、岸线深浅颜色与水波着色。
- `src/world/WorldPostFX.ts`、`WorldBloom.ts`：精细画质的低分辨率 GTAO、静态遮蔽缓存、抗锯齿、轻量辉光与输出色调。
- `src/world/WorldQuality.ts`：画质配置、自动像素预算、冷却与回升控制。
- `src/world/WorldMap.tsx`：地图图志、目的地信息、关卡选择、声音与存档。
- `src/world/world.css`：桌面、平板和手机界面。
- `src/world/worldData.test.ts`：地貌连通性、全部地点可达性、最短路径及非法存档检查。

地貌与装饰为程序化微缩模型，采用地块级通行规则；深水和陡峭雪峰不可通行，分别由栈桥和山间隘口连接目的地。未接入物理碰撞、动态地形生成、战斗或关卡场景。三维画面需要支持 WebGL 2 的浏览器。图形上下文中断和材质载入超时会提供重新载入操作。减少动态选项停止环境动画，保留用户触发的行走和镜头操作；对话框打开时暂停场景，后台页面停止渲染和环境声。

同材质地形和水面合批绘制，装饰采用实例化；总览使用较轻的几何，放大后恢复精细版本。像素比上限 1.5，并按画质限制三维总像素；阴影贴图 2048，按环境与行走状态降频更新。自动和流畅模式使用 FXAA，精细模式使用 2 倍 MSAA 和接触遮蔽。卸载时释放 GPU 资源与事件监听。详细设置、帧率测量和负载取舍见 [性能优化记录](world-performance.md)。

精细地形验证：131,982 个地表顶点，所有位置与法线均为有限值；沿相邻地块边缘抽查 14,364 个点，最大高度差小于 `1e-12`。第二版几何与截图检查保存在 `.work/world-quality-results.json`；后续性能优化及实际绘制间隔以 `.work/world-perf-release.json` 为准。

基础验证：`npm test` 的 16 项检查通过；`npm run build` 完成类型检查与生产构建。浏览器交互验证覆盖逐一行走至八个地点、选择关卡、刷新恢复、镜头旋转和缩放、拖动不误触行走、环境动画、声音开关，以及 1280×720、1440×960、1920×1080、390×844、768×1024、844×390 布局。另验证上下文中断重载、键盘行走、序幕跳转、材质请求失败、明确启用动态与本地 HTML 启动提示。具体结果位于工作目录 `.work/world-test-results.json`、`.work/world-resilience-results.json` 和 `.work/world-performance-check.json`。

实现依据为项目源码与官方文档：[OrthographicCamera](https://threejs.org/docs/pages/OrthographicCamera.html)、[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html)、[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)。采用已安装验证的 Three.js 0.186.0；运行时不依赖外部素材服务。
