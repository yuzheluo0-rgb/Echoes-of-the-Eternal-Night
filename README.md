# 永夜回响 · 余烬之境

当前首页是可探索的暗金卡通主世界：776 个正六边格、12 种地貌、48 个地点，包含跨 3～9 格的独立建筑群、3 格的支线与隐秘据点、9 种地貌桥梁与单格路边奇遇。
十二片风土各有 2～3 种只属于当地的动物在自由活动，点击可录进生物图鉴。海岸与岛屿自然排布；相机固定 2.5D 角度，可缩放、拖动并跟随人物。背景、深墨色海水与全部地图界面采用黑曜石、烟灰与旧金的配色，呼应封面的日蚀与提灯。

访问 `http://127.0.0.1:5173/#/world`。原动态载入界面保留在 `#/opening`。双击根目录 `start.bat` 可启动并打开预览。

点击格子预览路线，再次点击或按“前往此处”出发。建筑会阻挡通行，点击其占用格或上部模型可定位前庭。建筑群内部固定小路已移除。主要据点和秘境可选择关卡并记录目标，当前地图尚未接入各地区战斗。

世界最初只开放余烬营地所在的草原。其余十一处风土按「开拓之路」的章节顺序解封：每章都有各自的达成条件——立下誓言、处理奇遇、集齐印记、接下旧港工程、解开沙碑谜语、寻回遗物、在夜晚举行月潮仪式、勘测六格雪线、交还信物、重响哨钟、修好码头。在地图或手记中点开「开拓之路」查看当前目标与条件，亲赴门槛地点完成即可解封，同时获得 1 点烬火。封印区域的格子在寻路与小地图上都会被拦下，信标也不会亮起。

云层、飞鸟、树梢、芦苇、火山余烬、熔岩、溪流、海浪与薄雾持续变化。点击右上扬声器开启原创循环配乐《灯火渡海》与地区环境声。支持减少动画、后台暂停和自动画质。

世界时间默认从第一天 07:00 开始，现实 24 分钟流逝一个游戏日。清晨、中午、下午、傍晚、夜晚平滑改变太阳与月光方向、阴影、天空和水色；入夜后窗灯、篝火、晶石、熔炉和守夜人的提灯亮起。顶部时钟可暂停、调节 1× / 3× / 6× 流速，或等到指定时段。时间自动保存，读弹窗和离开页面时暂停。时钟使用流动金色荧光字、绕行光环与鎏金边缘。

南部的 **沉潮旧港** 是主世界修复任务：亲自走访六处援助地点，依次修复码头与吊机、点亮航灯、浮起归帆号；模型与灯光随阶段变化，完成后解锁免费归港与港口关卡。进度自动保存。

地点、关卡、支线、奇遇、手记、传送与说明弹窗已扩大到最多 760 像素宽，正文 16 像素、辅助说明 14 像素，按钮至少 44～48 像素高。长内容独立滚动，标题和关闭按钮始终可见；小屏保持正文大小。

## 启动

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。Windows 推荐双击 `start.bat`：启动或复用 5173 端口上的项目服务，并自动在浏览器打开动态预览。背景图片和截图本身是静态素材；请通过网页查看动效，不要直接双击 `index.html`。

本地已验证 Node.js 24.16.0、React 19.3.0、TypeScript 5.9.3、Vite 7.3.6。

```sh
npm run build
npm run preview
```

构建产物位于 `dist/`。原画、字体和声音运行时均无需请求外部服务。

## 保留的序幕体验

- 载入进度按六张图片实际完成加载和解码的数量计算；全部成功才启用「踏入永夜」。失败显示重试，18 秒超时也可恢复。
- 右上角「动态背景 / 开启动态」按钮直接控制播放与暂停。如果背景静止，点击「开启动态」即可恢复。普通地址尊重系统和本地保存的减少动态偏好；`?motion=on` 是明确开启动态的入口，应用后会移除参数，后续仍保存新的选择。
- 移动鼠标观察环境、人物、雾与余烬的分层景深；主按钮具有抬升、金色流光和悬停声。
- 背景持续缓慢推移；实时光雾层包含流动雾海、云层阴影、穿雾光束、日蚀辉光、门廊暖光、湿石反射和不同节律的烛火。提灯具有局部照明与地面光晕。
- 点击「踏入永夜」或按 `Enter`，播放推镜过场，进入三页序章。按钮、左右方向键和空格均支持翻页；`Esc` 返回序幕。
- 「永夜秘典」和四枚印记展示刃、焰、骨、镜的原画与风味文字。
- 点击右上角扬声器开启环境与交互音效；默认静音。风声、低鸣、古钟与和弦由 Web Audio 本地合成，包含卷积混响。
- 「旅途设置」支持音量、粒子、减少动态效果和「静赏长夜」。偏好保存在本地；系统的减少动态偏好用于初始设置。
- 「静赏长夜」隐藏控件以观赏原画；点击返回或按 `Esc` 恢复。对话框支持焦点限制和 `Esc` 关闭。

## 序幕美术与性能

2026-09-13 使用当前会话内置 `image_gen.imagegen` 工具生成新的教堂场景与透明人物立绘。原图保留，网页资源使用 WebP：场景约 383 KB，人物约 431 KB，首帧模糊预览 388 字节。提示词、尺寸与处理方式见 [载入界面原画记录](docs/opening-art-prompts.md)。

场景采用 CSS 合成与 2.5D 视差。原画保持原始清晰度，独立 WebGL 光雾层按约 30 帧/秒更新，绘制面积上限约 76 万像素。光源坐标绑定原画，随桌面与手机裁切、景深移动和镜头缩放同步；日蚀辉光利用原画亮度保留尖塔遮挡，桥面反射受原有暖色高光约束。

粒子集中在另一个 Canvas，绘制上限约 30 帧/秒，像素比上限 1.5。设置和秘典打开时暂停背景光雾与镜头；后台页面也暂停镜头、光雾、粒子绘制及环境声。减少动态选项保留静态光照并停止镜头、粒子和逐帧光雾。WebGL 不可用时仍可观看 CSS 场景并正常操作；上下文恢复后自动重建光雾层。

Noto Serif SC 与 Cormorant Garamond 字体经过字符子集化并保存到 `public/fonts/`；同目录保留字体的 OFL 许可。界面文字是可选择、可访问的原生文本。

## 验证

36 项自动测试通过，覆盖规则、地图连通性、跨格占地、最短路线、存档迁移、支线奖励、奇遇选择、传送费用、港口修复、区域解锁与章节门槛、画质预算和时间系统。其中一项完整走完 11 章解锁链，验证十二片风土均可抵达。浏览器实测旧港三阶段、六处援助、支线、秘境、奇遇、信标和读档流程，另验证真实音频输出、静音回收、动态像素变化、动画冻结、建筑拾取和手机图志。新增时间流速、保存、离开暂停、五个时段的光照与 8 种尺寸下的弹窗阅读检查，详见 [日夜系统](docs/world-time.md)、[地图说明](docs/world-map.md) 与 [性能记录](docs/world-performance.md)。
`npm run build` 执行 TypeScript 检查并生成生产构建。浏览器检查覆盖实际载入与失败重试、景深和悬停反馈、秘典切换、声音启动与关闭、设置保存、序章翻页、键盘焦点和九种屏幕尺寸。光照另检查真实像素随时间变化、暂停与继续、减少动态、手机光源映射，以及 WebGL 不可用和上下文丢失恢复。

## 文件

- `src/main.tsx`：当前入口。
- `src/opening/Opening.tsx`：载入、标题、序章、秘典和设置。
- `src/opening/preload.ts`：真实图片预载入、解码、取消和错误恢复。
- `src/opening/OpeningAtmosphere.tsx`：环境粒子。
- `src/opening/OpeningLightField.tsx`、`cinematicLight.ts`：实时光照与雾气、原画坐标映射、GPU 资源生命周期。
- `src/opening/cinematic.css`：持续镜头运动、提灯照明和背景暂停。
- `src/opening/opening.css`：分层场景、动画与响应式布局。
- `src/audio.ts`：本地声音与混响。

先前的战斗原型保留在项目中，说明见 [战斗原型记录](docs/battle-prototype.md)。当前入口不会加载战斗页面。
